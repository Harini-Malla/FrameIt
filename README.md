# FrameIt
photobooth - capture the moment that is worth keeping ✨

--> choose your frame
--> start timer
--> capture the moment
--> add the filter, emojis 
--> give your moment a name
--> download or share your moment

this is a light-weight web based photobooth application that lets users frame snapshots, run a countdown timer, apply fun filters and emojis, and download the final capture.

## ✨ Features
* **Custom Frames:** Pick your layout before capturing the shot.
* **Hands-Free Timer:** Built-in countdown so you can strike the right pose.
* **Photo Modes:** 
  * 📸 Solo Photobooth Mode
  * 👨‍👩‍👧‍👦 Family Photo Mode
* **Creative Editing:** Add filters, emojis, and captions/names directly onto your photos.
* **Save & Share:** Download high-resolution images instantly to your device.
  
📌📌📌 NOTE on project version:
this is the starting version of the project - so only photo booth and the family photo mode is available.. in the latest version (Kshanam) all the features are available

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla js)
* **APIs:** HTML5 MediaDevices API (`getUserMedia`) for camera access, HTML5 Canvas API for image rendering and frame manipulation
